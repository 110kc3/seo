## Findings, ranked

1. **The rail has still never settled.** `settlements: 0`, `total: "0"`. Every
   line of payment code is now verified except the only one that matters
   commercially. The $0.05 self-payment (TODO → "The one that matters") is
   still the single highest-value ten minutes available.
2. **Distribution is written but 0% executed.** All 8 listings are self-authored
   seeds; every channel in `docs/distribution.md` (awesome-mcp-servers,
   Awesome-llms-txt, llms-txt-hub, agentswelcome.dev directory, Show HN) awaits
   a go. The site cannot get organic registrations nobody has heard of it.
3. **The Track A shopfront fails its own audit.** The
   `agent-readability-service` listing points at `https://github.com/110kc3/seo`
   — an origin we don't control — so its score badge says **E 51**. An
   agent-readability service whose own listing grades E is an anti-pitch. Fix:
   give the service a page on an origin we own (e.g. a `/services/…` page on
   `kc-it.pl`, which scores A 100, or a section page on the index itself) and
   `[update]` the listing URL.
4. **Early decision-gate readout (day 4 of 7).** `agent_share` **3.2%** — 60
   `ai_crawler` + 293 `script` hits in 30d, 75 free-score calls, 22 llms.txt
   fetches, **7 hits on the audit path (all 402 bounces, none paid)**. That is
   non-trivial agent traffic for a site with zero inbound links; the gate leans
   **"keep feeding it + run the Show HN"**, not "abandon". Re-read ~2026-08-01
   before acting.
5. **Known debt confirmed still open** (both already in TODO): the
   over-privileged `CF_ANALYTICS_TOKEN` mirror, and the missing Zone → Bot
   Management → Edit permission that blocks `robots-allow` (three fleet sites
   held at 90/100).
6. **One accepted limitation in `worker/x402.js`, noted, not worth fixing:**
   the KV nonce reservation is get-then-put, and KV is eventually consistent
   across edge locations, so two simultaneous replays at different edges could
   both pass the check and both reach `/settle`. The damage is bounded
   on-chain: EIP-3009 burns the authorization nonce, so the second settle
   *reverts* — the payer is never double-charged; we just make one wasted
   facilitator call. A Durable Object would close it and is not worth it at
   $0.05 a call.

## How to earn more from *this* project

In order of expected value per hour:

1. **Prove the rail** ($0.05 through it, replay refused, visible on basescan
   and the dashboard). Everything else advertises an endpoint that has never
   demonstrably worked.
2. **Execute distribution** — the commands are already written in
   `docs/distribution.md`; the Show HN draft is done. This is the only lever
   that produces buyers at all.
3. **Fix the shopfront listing** (finding 3) and turn the fleet sweep into the
   sales page: "12 sites, average 68.6 → 97.5, nine at 100/100" is a real
   before/after case study for Track A — publish it as a page and link it from
   the "For humans" section.
4. **Get into the x402 Bazaar** (CDP key, already in TODO as optional —
   promote it). The Bazaar is where paying agents actually browse; ~112
   endpoints today at $0.001–0.01/call, so a $0.05 niche audit is well within
   market shape. One CDP key also covers every future service.
5. **Widen the paid surface on the same rail** (only after ≥1 organic payment):
   a deep audit (`/api/audit-deep`, multi-page crawl, $0.25–$1), and a
   monitoring product (weekly re-score + webhook) sold as **prepaid x402
   credits** keyed to the payer address — x402 has no subscriptions, so a
   credit balance is the honest model.
6. **Track A outreach** stays the realistic near-term money: humans pay
   $29–489/mo for AI visibility; the audit is the lead magnet (free score →
   emailed report → `[hire]`).

XiuRouter

XiuRouter is a usage-based model API service that connects applications, AI agents, and developer tools to leading models through one API. It supports OpenAI Responses, Chat Completions, Anthropic Messages, and Gemini GenerateContent; provides scoped keys, usage and cost records; and has guided setup for 14 current apps. Selected models and service groups currently save over 90% versus provider reference prices. XiuAI and its products are operated by XiuLab Inc, a U.S. corporation.
